    Stack Tecnológica¶

    Frontend e Backend vivem em repositórios separados e se comunicam exclusivamente via API REST.

    Frontend¶

    Tecnologia Papel no projeto
    Next.js Framework React (App Router) — páginas, rotas e renderização do site
    React Biblioteca de UI sobre a qual o Next.js é construído
    TypeScript Tipagem estática em todo o código do frontend
    ESLint Padronização e qualidade do código

    Backend¶

    Tecnologia Papel no projeto
    NestJS Framework Node.js estruturado em MVC (Controller → Service → Model)
    Node.js Runtime JavaScript/TypeScript do backend
    TypeScript Tipagem estática em todo o código do backend
    TypeORM ORM — mapeia entidades para tabelas do PostgreSQL (o "Model" do padrão MVC)
    Swagger Documentação interativa da API, gerada automaticamente (/api)
    Jest Testes unitários e end-to-end
    ESLint Padronização e qualidade do código
    Prettier Formatação automática do código

    Banco de Dados¶

    Tecnologia Papel no projeto
    PostgreSQL Banco de dados relacional principal

    Infraestrutura¶

    Tecnologia Papel no projeto
    Docker / Docker Compose Ambiente de desenvolvimento containerizado — cada repositório (Frontend, Backend) tem seu próprio Dockerfile e docker-compose.yml
    GitHub Hospedagem dos repositórios e organização (Eldo-Eletrostatica)
    GitHub Actions CI/CD — hoje usado para publicar esta documentação no GitHub Pages a cada push
    npm Gerenciador de pacotes de Frontend e Backend
